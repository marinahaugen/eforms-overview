# eForms 16 & 29 — Wizard Field Overview

Interactive reference for EU eForms field requirements and SDK codelist values, covering **Contract Notice (eForm 16)** and **Contract Award Notice (eForm 29)**.

**Live:** [eforms-overview.marina-254.workers.dev](https://eforms-overview.marina-254.workers.dev/)

## What's Inside

- **281 fields** across 8 wizard steps, showing requirement levels (M/CM/EM/O) for both forms
- **76 Code fields** with expandable dropdown values from the EU and Norwegian eForms SDKs
- Filters by form (F16/F29/Shared/Unique), requirement level, data type, and free-text search
- Reference list tracing every data point back to its source (Excel, SDK YAML, EU Genericode)

## Updating

The HTML is generated by a Python build script (not in this repo). To regenerate and deploy:

```bash
cd /Users/marina/bootcamp
python3 build-eforms-overview.py
cp eforms-wizard-overview.html eforms-overview/index.html
cd eforms-overview
git add index.html && git commit -m "Update overview" && git push
```

Auto-deploys to Cloudflare on push.

## Verifying Data Integrity

```bash
cd /Users/marina/bootcamp
python3 -m pytest test_eforms_overview.py -v
```
